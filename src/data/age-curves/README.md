# 選手ごとの年齢曲線（試作0.41.0）

通常プレイの架空4球団120人を、一人一JSONで保持します。実在選手の査定値ではなく、`age-curves-v1`の固定入力例です。2026年候補70人とは分離し、未確定データを補完しません。

- `aonagi/`：青凪、`hoshihara/`：星原、`kohaku/`：琥珀、`asagiri/`：朝霧。
- [index.ts](index.ts)に選手IDとファイルを明示登録します。ID・ファイル名・本人の名簿を一致させます。
- 身体`physical`・技術`technique`・判断`judgment`に、独立した6項目を持ちます。

| 項目                 | 単位・意味                            |
| -------------------- | ------------------------------------- |
| growthStartAgeMilli  | 成長期の開始。年齢×1000               |
| growthPeakAgeMilli   | 成長速度が最大になる年齢×1000         |
| growthEndAgeMilli    | 年齢成長が終わる年齢×1000             |
| declineStartAgeMilli | 衰退開始の年齢×1000。成長終了と分ける |
| growthPermille       | 個人の成長速度。1000で等倍、0〜2000   |
| declinePermille      | 個人の衰退速度。1000で等倍、0〜2000   |

開始＜頂点＜終了≦衰退開始を守ります。年齢の検査範囲は開始0〜78000、頂点〜79000、終了〜80000、衰退開始〜100000です。起動時にIDから再生成せず、このJSONを保存内へ複製します。初期例は群ごとの基準時期・個別のずれ・速度を固定してあり、現実の分布として校正したものではありません。

共通の年間量・才能係数・能力の分類は[config/aging.ts](../../../config/aging.ts)、計算は[src/world/aging.ts](../../world/aging.ts)、式と互換性は[育成ガイド](../../../TRAINING-IMPLEMENTATION.md#0410選手別の年齢変化と衰退)です。

編集後は`npm.cmd run data:check`で人数・ID・登録漏れ・曲線・係数を検査し、新規プレイで確認してください。既存の保存にある曲線は置き換えません。内部の将来曲線を成長予測として画面へ出さず、画面には確定した能力の増減だけを表示します。
