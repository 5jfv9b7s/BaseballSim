# 2026年の初期データ候補

提供資料 `baseball-initial-data-2026-seibu-v0.11/initial-data-2026/` の候補を、編集・単球検証のために分離しています。**1球団70人の候補で、正式な12球団データではありません。** `seibu` は取込元を識別するフォルダ名です。ゲーム内の球団名は未決定のままです。

現行の架空120人の追加能力・適性は、別の[development/README.md](../development/README.md)で編集します。そちらの定義v19追加によって、この候補の未決定事項や正式投入可否を変更していません。

## ファイルと編集先

| 場所                                                                 | 内容                                                                                                                       |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| [seibu/players/](seibu/players/)                                     | 固定選手IDごとの70 JSON。プロフィール、22基本能力と上限、9位置の適性・習熟、投手適性、才能・向上心、持ち球を一人分ずつ編集 |
| [seibu/metadata.json](seibu/metadata.json)                           | 候補の版、資料更新日、未決定の球団名、取込元3ファイルのSHA-256                                                             |
| [seibu/locations.json](seibu/locations.json)                         | 出生地の国・地域辞書                                                                                                       |
| [seibu/preview-templates.json](seibu/preview-templates.json)         | 資料由来の追加4球種の仮テンプレート。実測値ではない                                                                        |
| [seibu/index.ts](seibu/index.ts)                                     | 全選手の明示的な読み込みと候補全体の検査・複製                                                                             |
| [../../initial-data/types.ts](../../initial-data/types.ts)           | 候補専用の型。正式プレイの選手型とは分離                                                                                   |
| [../../initial-data/validation.ts](../../initial-data/validation.ts) | 単位・上限・参照・未決定状態の検査                                                                                         |

現在値と上限は0～120000の整数（表示値の1000倍）。習得進度・配球案は0～100000（百分率の1000倍）、球速は0.01 km/h、リリースはmm、回転数はrpm、回転軸は単位ベクトルの1000000倍です。固定適性と才能・向上心へ成長上限を追加しません。各値の由来・生成版・候補状態を保持してください。

IDは名前変更や並べ替えで変えません。追加する場合は新しい固定IDのJSONを作成し、`index.ts`へ明示的に追加します。持ち球は所有者のJSONに置き、全体で一意の`pitchId`と一致する`playerId`を使います。野手へ実行時に投手の持ち球をコピーしません。

本形式v1は2026年候補専用です。球団名・開始日・資格・初期編成等を確定して正式投入する際は、候補の制約を外すだけではなく、所属・契約等を含む正式な変換と版管理が必要です。

## 取込元との関係

最初の取込は次のコマンドです。`--source`はパッケージ内の`initial-data-2026`を指定します。

```powershell
npm.cmd run data:import-candidates -- --source "Docs/野球シミュレーションゲーム_Codex引き継ぎ一式/baseball-initial-data-2026-seibu-v0.11/initial-data-2026"
```

元の投影データ・所在地辞書・物理ルールのバイト列ハッシュを提供資料の検証記録と照合し、74ファイルへ分けます。実在名との対応表、研究成績、調査URLは取込対象にしません。資料の再生成スクリプト全体を実行するコマンドではありません。

末尾へ`--check`を加えると、現在の入力と取込予定の一致だけを検査します。**手編集した既存ファイルは再取込で上書きしません。** 相違や余分な選手ファイルを検出すると停止します。手編集後の不一致は、元資料との差分として確認してください。独自の変更には`datasetVersion`と由来を付け、元資料のハッシュを編集済みファイルの証明として扱わないでください。

```powershell
npm.cmd run data:check
node --test tests/initial-candidates.test.ts
```

通常の入力検査は上記です。`data:check`は全候補の構造を検査し、習得進度100000かつ対応済みの球種だけを単球計算へ送ります。未習得・未対応の候補を正式使用可能へ変換しません。取込元と完全一致していなくても、型・参照・候補状態が正しいかを検査します。JSONは2空白で整形してください。

## 画面で確認する

本画面下部の「シミュレーション開発ツール ↗」→「初期データ候補」で、名前・区分による絞り込み、22能力と伸び代、9位置、持ち球・単球検証、由来を確認できます。検証専用Workerが計算し、正式世界の名簿・日付・成績・DBを変更しません。球種・打者・カウント・seedが同じなら同じ1球結果になります。

追加4球種（ツーシーム、シュート、ナックルカーブ、パーム）は候補検証専用のカタログで対応します。正式プレイの9球種は維持します。配球案は保存・表示のみで自動配球へは未接続です。単球は指定された習得済み候補を1種類だけ使います。検証共通条件は[config/initial-candidate-preview.ts](../../../config/initial-candidate-preview.ts)です。

## 保持した未決定事項

`readyForGameImport: false`、代表位置未決定17人、外国人枠資格未決定70人、僅少球種の採否、資料の`blockers`を保全しています。生年月日の月日は架空設定、能力・上限は未校正の候補です。参考成績をゲーム内の成績カウンタへ加算しません。

現行v11式では162持ち球中122件が通常抽選で基本MAXへ届きません。画面に抽選範囲を表示し、再現性や球速幅を逆算して修正する処理は追加していません。全能力の試合計算、成長・衰え・覚醒、正式編成、契約、残る11球団の取込は後続工程です。
