# 投手ごとの持ち球を編集する

0.26.0以降の新規プレイでは、このフォルダが持ち球の編集元です。全4球団・24投手・80持ち球を明示しています。すべて架空の仮設定で、実測値・校正済み査定・最終的な能力バランスではありません。

## ファイルの構成

| 球団           | フォルダ                 | 投手の例                                                                 |
| -------------- | ------------------------ | ------------------------------------------------------------------------ |
| 星原フォックス | [hoshihara/](hoshihara/) | [川瀬 陸](hoshihara/player-a-10.ts)、[羽田 匠](hoshihara/player-a-11.ts) |
| 青凪ハーバーズ | [aonagi/](aonagi/)       | [player-h-10](aonagi/player-h-10.ts)                                     |
| 湖白スワンズ   | [kohaku/](kohaku/)       | [kohaku-player-a-10](kohaku/kohaku-player-a-10.ts)                       |
| 朝霧フォックス | [asagiri/](asagiri/)     | [asagiri-player-h-10](asagiri/asagiri-player-h-10.ts)                    |

各フォルダに一軍・二軍用の投手6人を含みます。昇降格しても同じ選手ID・持ち球を使います。ファイル名は不変の選手ID、先頭コメントは氏名です。[index.ts](index.ts)で全選手の配列をまとめます。

一つの選手ファイル内で、各持ち球の球速・制球・再現性・回転・リリースを編集できます。旧版用の `../球団名.ts`、`../../farm/*/repertoires.ts`、`../pitch-profiles/` を同時に編集する必要はありません。選手の氏名や打撃・守備能力は [データ全体の案内](../../README.md) を参照してください。

## 項目と反映先

| 項目                       | 意味・単位                       | 現在の反映                                         |
| -------------------------- | -------------------------------- | -------------------------------------------------- |
| `pitchId` / `playerId`     | 持ち球の固定ID / 所有者の固定ID  | 既存IDを改名せず、新しい持ち球には一意のIDを付ける |
| `pitchTypeCode`            | 球種辞書のコード                 | 球種ごとの配球重み・表示名を参照                   |
| `acquisitionProgressMilli` | 習得進度。100000で完了           | 未習得球は投球に使わない。習得・成長処理は未実装   |
| `control.valueMilli`       | 0〜120000、1000で1ポイント       | 狙った位置への精度                                 |
| `repeatability.valueMilli` | 同上。上限以下                   | 球速と回転のばらつき                               |
| `velocity`                 | 0.01 km/h単位。中心・MAX・基礎幅 | 投球の球速                                         |
| `delivery.spinRateRpm`     | 基本回転数 rpm                   | 各投球の回転・変化量                               |
| `delivery.spinSpreadRpm`   | 回転の片側の基礎幅 rpm           | 再現性に応じて縮小して抽選                         |
| `delivery.spinAxis`        | 単位ベクトル×1000000             | 横・縦の変化量。角度ではない                       |
| `delivery.release`         | 左右・高さ・前方距離 mm          | 記録と表示のみ。軌道への効果は未実装               |

数値の検査範囲・座標・計算式は [球種の編集ガイド](../../pitch-types/README.md) を参照してください。軸とリリース左右は**右投手基準**で記入します。左投手の反転は計算・表示時に一度だけ行います。実際に保存された投球の値を編集元へコピーする際は、この向きの違いに注意してください。

`delivery` は全項目を記入します。現在の新規データでは省略を検査エラーにします。エンジン自体の共通テンプレートへのフォールバックは、旧保存や従来の入力用に維持しています。配球重みは現在も球種ごとに共通で、個人別の配球割合は未実装です。

## 追加・変更と確認

1. 既存投手は該当する選手ファイルを編集します。新しい投手はファイルを作り、index.tsへのimportと配列への結合、選手名簿・登録・編成も追加します。
2. 新しい持ち球には一意のpitchIdと正しいplayerIdを指定します。新球種なら辞書と共通特性も追加します。
3. `npm.cmd run data:check`で参照・重複・数値・投球可能性を検査し、`npm.cmd run check`で型・計算・保存を確認します。
4. 新しいプレイを準備して「チーム」→投手名→「球種の特性（試作）」を開きます。開始済みのプレイはその時の入力を使い続けます。

新規日程は世界v15・定義v15、試合はv11です。計算式・共通係数・乱数の消費順・内部保存v016は変えていません。定義v14の旧世界は個人値を補完せず、共通テンプレートのまま再開します。新しい定義の保存には0.26.0以降が必要です。

川瀬のストレートは2350 rpm・再現性76、羽田は2100 rpm・再現性65です。軸も異なるため、同じ球速へ揃えても変化量が異なります。回転が多ければ必ず強い、という査定ではありません。通常球速と制球は従来値を維持しました。各値はファイルに明記した固定入力で、実行時に名前・ID・配列順から生成しません。
