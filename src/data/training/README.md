# 通常練習の初期指定（0.37.0）

「チーム」→「育成・練習」で変更する通常練習の開始時入力です。**この版は設定と保存のみで、日次の練習効果・疲労調整・実戦経験・恒久成長は未接続です。** 強めを選んだだけで成長量や疲労は変わりません。

## 編集先

- [index.ts](index.ts)の`DEFAULT_TRAINING`：架空120人へ使う共通の開始時指定。初期例は「基本能力全体・普通・疲労による調整を許可」です。成長係数の最終仕様ではありません。
- 同ファイルの`PLAYER_TRAINING_OVERRIDES`：固定選手IDをキーに、個人の初期指定を追加します。省略選手は共通設定を使います。未知の選手IDは検査で拒否します。
- [targets.ts](targets.ts)：能力群のID・表示名・共通能力コード。ミート全体は左右2項目、全体指定は22項目へ展開します。重複・空の群・未知項目を拒否し、同じ能力を二重に含めません。
- [../world/training-plans.ts](../world/training-plans.ts)：新規定義v20の入口。初期指定と対象辞書を開始時に複製します。

個別指定は`target: { kind: 'ability', abilityRef: { scope: 'batting', code: 'contactVsRight' } }`、群は`target: { kind: 'group', groupId: 'contact' }`のように指定します。`intensity`は`light / normal / hard / rest`、`autoAdjustForFatigue`は真偽値です。終了日指定はこの画面では扱わず、保存内の`effectiveUntil`はnull（終了指定なし）です。

持ち球は`scope: 'pitch'`と`pitchId`、`code: 'control' / 'repeatability'`を指定します。本人以外の球は使えません。守備習熟は`scope: 'position'`、`positionCode: 'P' ... 'RF'`、`code: 'familiarity'`です。DHは対象にしません。球速・回転等、その他の球種項目、新球種・傾向変更・キャンプはまだ選べません。

## 操作・一括編集

1. 選手名で一人を選び、チェックで複数選手を選びます。一二軍・投手/野手・代表位置・名前で絞れます。
2. 個別能力、能力群、守備習熟、本人の持ち球の制球/再現性、強度、自動調整の希望を編集します。現在の値・上限は保存内の選手データです。成長予測を生成しません。
3. 複数選手で異なる項目は「設定が異なります（変更しない）」と表示します。操作した項目だけを変更し、他の項目を先頭選手の値で上書きしません。共通しない持ち球は一括の候補へ出しません。
4. 「変更を保存」、またはゲーム内の別画面へ移る操作で、変更した選手をまとめて保存します。「変更を取り消す」で開始時の編集内容へ戻せます。
5. 保存成功後にだけWorkerの正本と表示を確定します。失敗時は画面を移らず編集内容を残します。再試行で二重に更新しません。ブラウザ自体を閉じる前は「変更を保存」を使ってください。

表示外に選択選手がいる場合は人数を表示します。「表示中を選択」は現在表示している選手だけへ選択を置き換えます。未変更の閲覧・絞り込み・選択・能力表示はWorkerの状態変更指示や乱数を発生させません。試合開始後・進行中・全日程終了後は閲覧のみという今回の編集境界です。

## 保存と互換性

新規は`world-definitions-v20`、`club-management-v2`、`training-plans-v1`、対象辞書`training-targets-v1`です。世界の計算v15・試合v11・保存エンベロープv016を維持し、管理状態の構造版で練習指定の有無を区別します。通常の起用設定とは別の`management.training`に保持し、変更指示は既存の管理履歴へ日付とともに記録します。

開始後に編集元を変えても既存プレイは変わりません。旧v19以前の保存は当時の管理v1を保持し、練習設定を後付けしません。0.36.0以前のアプリはv20保存を読めません。旧`createPlayerDevelopmentWorld/Definitions`の入口もv19のまま残します。

通常の初期名簿、提供候補70人、持ち球、身体入力、試合係数、カレンダーの操作仕様は変更しません。この画面の完成はv1.0や育成全体の完成を表しません。未決定の成長式・配分率・自動調整の閾値を0や仮の予測値で補っていません。
