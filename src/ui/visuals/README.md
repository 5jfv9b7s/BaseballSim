# 野球画面の共通表示部品

ホーム（0.29.0）から導入しました。表示だけを担当し、保存・試合計算・乱数に依存しません。球団・選手の識別子と数値は呼び出し元の保存内データを使います。

## 表示ルール

- 球団名を主情報として残し、`ClubMark` を隣に添えます。文字印は識別用で、正式ロゴではありません。小型版は日程・順位表に使います。
- `club-identity.ts` は表示専用の文字印と配色です。既存の球団IDで引き、配列順や勝敗から色を生成しません。未知のIDは灰緑色の「球」と実際の球団名を表示します。
- `MatchScore` はビジターを左、ホームを右に固定します。未実施は「—」、実際の0点は「0」、2桁以上も省略しません。読み上げには球団名と得点を含めます。
- 図形は同じ情報を二重に読み上げないよう装飾扱いとし、色だけで自球団・状態・結果を区別しません。文字、HOME/VISITOR、短い状態ラベルを併記します。
- 主操作は濃い背景に明るいボタン、選手詳細とレポートの遷移は下線、選択中の情報は下線と背景を併用します。44px以上の操作領域を保ちます。
- ホーム用の配置は `../home-dashboard.css` に隔離しています。別画面へ展開する場合はこの配置をコピーせず、同じ部品に実データを渡します。

## データと簡略表現の区別

現在の保存形式には球場・開始時刻がないため未設定です。正式な球団カラーの指定もなく、ここでの配色・文字印はUIの実装判断です。能力や評価値ではありません。ユニフォーム図と背番号欄は、0.30.0でユーザー指示により撤去しました。

先発表示の判断は `../home-view.ts` へ分離しています。確定先発を優先し、試合前の自球団だけ、同じ試合IDのWorkerプレビューを「先発候補」として表示します。相手の予告先発をUIで独自計算しません。

素材の出典、将来の正式エンブレムの要件は [UI-ASSETS.md](../../../UI-ASSETS.md) を参照してください。今回、既存の提供SVG6点は変更していません。

## 展開時の確認

能力バー、疲労ゲージ、球種の軌道、成績グラフは、各データの単位・上下限・観測対象を明示してから追加します。このホーム改修ではそれらの架空の値やモデルを作っていません。
